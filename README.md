# 🏠 Real Estate Market Analysis – Tableau Dashboard

## 📌 Project Overview
This project presents a comprehensive **Real Estate Market Analysis Dashboard** built using **Tableau**. It delivers insights into property pricing trends, construction growth, furnishing impact, property type distribution, loan eligibility, and bedroom-based price variations.  

The goal is to transform real estate data into actionable visual intelligence that supports smarter investment, pricing, and development decisions.

## 📂 Dataset Description
The dataset contains structured real estate data across cities, property categories, and financial attributes.

**Key Fields Include:**
- City and State  
- Property Type *(Apartment, Villa, Studio, Row House, Penthouse)*  
- Average Property Price  
- Year Built / Construction Year  
- Furnishing Type *(Furnished, Semi-Furnished, Unfurnished)*  
- Parking Availability  
- Loan Eligibility Status  
- Number of Bedrooms :contentReference[oaicite:3]{index=3}

## 📈 Dashboard Features

### 🔹 Market Performance Analysis
Compares average property prices across cities and states, highlighting high-value markets and premium locations.

### 🔹 Yearly Construction Trend
Visualizes long-term construction growth patterns, revealing development cycles and market expansion phases.

### 🔹 Furnishing Type Analysis
Shows how furnished and semi-furnished properties typically command higher prices than unfurnished homes.

### 🔹 Property Type Distribution
Breakdown of Apartments, Villas, Studios, Row Houses, and Penthouses to understand supply distribution.

### 🔹 Loan Eligibility Insights
Highlights financial accessibility of property types and how loan approval trends affect buying patterns.

### 🔹 Bedroom-Based Pricing Analysis
Demonstrates how increasing bedroom count correlates with higher property prices.
